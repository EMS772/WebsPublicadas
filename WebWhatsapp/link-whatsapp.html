¿Cómo crear un link de WhatsApp con mensaje?

El formato de un link de WhatsApp con mensaje predefinido es: https://wa.me/[número]?text=[mensaje codificado]. WaTools genera este link automáticamente mientras escribes, codificando correctamente el mensaje para que funcione en todos los dispositivos. No necesitas conocer el formato técnico ni hacer nada manualmente.
